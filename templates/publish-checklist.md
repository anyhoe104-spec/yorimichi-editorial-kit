# 公開前チェックリスト

記事を公開する直前に、上から順に確認する。

## 1. 事実

- [ ] 内部編集メモの基準時点と、本文が扱う範囲が一致している
- [ ] 「実装済み」に分類したものだけを、事実として書いている
- [ ] 設計・検討中のものを、完成として書いていない
- [ ] 実機で確認していない動作を、確認済みとして書いていない
- [ ] 価格・収益・利用者数を、企画上の仮説として明記している
- [ ] 後続の改修を、この回の時点の出来事として書いていない

## 2. 文体

- [ ] 担当部員の文体仕様のチェックリストを通過している
- [ ] 他部員の語りの型が混入していない
- [ ] 抽象的な締め（「大きな一歩」など）を使っていない
- [ ] AIを万能の相棒として描いていない

## 3. 公開範囲

- [ ] 本文・SNS本文にコミットハッシュ、PR番号、ローカルパスがない
- [ ] APIキー、トークン、アカウントIDがない
- [ ] 公開を決めていないURLが入っていない
- [ ] 画像内に読める日本語、URL、ロゴ、透かしがない

## 4. 画像

- [ ] 画像配置ガイドの指定位置と、現行本文の見出し・段落が一致している
- [ ] 人物の連続性が過去回と大きく変わっていない
- [ ] 完成後の成果物を初期回の画面として見せていない。該当する場合はキャプションで明示している

## 5. 透明性

- [ ] 冒頭に、部員が架空であることの注記がある
- [ ] 末尾に、進捗が実際の記録にもとづくことの注記がある

## 6. 公開操作

- [ ] 公開は手動で行う。無断の自動投稿・予約投稿をしない
- [ ] 公開後、掲載URL、媒体、公開日時、使用画像を記録する
