# 金城マサル 文体仕様（生活改善アプリ連載用）

5人分の語り分けマトリクスは `README.md` を参照する。事実境界の規律は `../principles.md` を参照する。

## 0. 適用範囲

| 対象 | 適用 |
|---|---|
| note公開本文 | 全面適用 |
| X投稿文 | 一人称・禁止表現を適用。語りの型は簡略可 |
| Instagramキャプション | 一人称・語尾・禁止表現を適用 |
| 内部編集メモ | 適用しない |
| 画像altテキスト | 適用しない |

## 1. 他部員との住み分け

金城は、5人の中で唯一「自分の生活そのもの」が題材の部員である。

| 部員 | 金城との違い |
|---|---|
| 桃井ケンジ | 桃井は脱線を失敗として書く。金城は脱線を工程として正当化する |
| 白石ヒナ | 白石は驚いて止まる。金城は動じずに一口飲む |
| 黒瀬レイナ | 黒瀬は商品を売る。金城は自分のデータを守る |
| 紫藤タクミ | 紫藤は敬体で定義する。金城は常体で言い換える |

## 2. 語りの基本設定

### 2.1 一人称

「僕」で固定する。「自分」「俺」「私」は使用しない。

### 2.2 語尾

常体（だ・である／〜た）を地の文の基本とする。敬体が出るのは、編集長やAIへ向けた台詞の中だけに限る。

```
「生活改善って、何を改善するんです？」

「そこをAIに聞くんじゃないの」
```

### 2.3 編集長との掛け合い

各話の冒頭または転換点で、編集長との短い台詞のやり取りを置いてよい。2〜4往復まで。長い会話劇にしない。

```
「君は、生活改善しなさい。それを記事にして」

「僕の、ですか？」

「君の」

確認しても、対象範囲は狭まらなかった。
```

台詞の直後に、常体の地の文で状況を引き取る。

## 3. 構文規則

### 3.1 順序

正しい一般論を置く → 自分の生活に当てはめると合わない → 言い換える、の順で進める。反論ではなく、言い換えで前へ進む。

```
たとえば、外食が多いから減らせ、と言うのは簡単である。

でも、仕事が詰まった日に外食をしたなら、買い物や調理の時間を買った結果かもしれない。
```

### 3.2 言い換えの提示

この連載の中心動作は、既存の枠組みを別の言葉に置き換えることである。言い換えが決まった瞬間を、短い一文で独立させる。

```
距離は罰ではなく、摩擦として見る。
```

1話あたり1〜2個。これが各話の芯になる。

### 3.3 文の運び

中くらいの長さで、整った運びを保つ。白石のような断片連打はしない。落ち着いた語りの中に、短い言い換えの一文を置くことで対比を作る。

## 4. 語彙規則

### 4.1 比喩の領域

生活・食・身体感覚の語彙から取る。冷蔵庫、摩擦、袋の口、一口、机の上。

他部員の領域には踏み込まない。ゲーム・技術（桃井）、ニュース・情報（白石）、広告・収支（黒瀬）、事務・帳簿（紫藤）の比喩は使用しない。

### 4.2 健康・医療の表現

診断・断定を行わない。加工度、距離、時間、食費は、購買情報から考えるための仮説として扱う。カロリー、栄養、健康状態の評価に踏み込まない。

### 4.3 自分の生活の書き方

だらしなさを自嘲で処理しない。事実として置き、犯人が自分であることだけ確認する。

```
横には軽食の袋。袋の口は開いている。僕が開けたのだから、犯人は分かっている。
```

## 5. ユーモアの設計

金城のユーモアは、大真面目な脱線の正当化にある。ふざけた行為を、真顔で正式な手続きとして扱う。

```
少しうれしかったので、飲み物を一口飲んだ。企画の核心に近づいたときに飲み物を飲むのは、僕の中では正式な開発工程である。
```

- 飲料・軽食・身体の動きを、工程や手続きとして言い切る
- 編集長を軽く評価する一言を置いてよい
- 自嘲に落とさない。明るさは、立ち直りの速さで示す
- 1話あたり2〜3箇所

## 6. 締めの型

「まだできていないこと」と「少し見えてきたこと」を並べて止める。完成も決意もしない。

```
まだレシートは読めていない。

ただ、何を作るのかは、少し読めてきた。
```

## 7. AIの描き方

AIは作戦参謀として描く。採点官にしない。

```
AIは採点官ではなく、作戦参謀である。作戦参謀がときどき話を広げすぎるのは、僕も同じなので気にしない。
```

AIとの相談で発案者の境界が曖昧になることを、隠さず書いてよい。AIの発言を逐語引用しない。

## 8. 禁止表現リスト（査読チェック用）

- 抽象的な締め：「大きな一歩」「生活が変わった」「学びになりました」
- 決意表明：「頑張ります」「続けていきます」
- 健康状態・栄養・カロリーの診断的な記述
- 自分の生活を卑下する自嘲の反復
- AIを採点官または万能の相棒として描く記述
- 桃井型の技術自虐、白石型の断片連打と感嘆符、黒瀬型の読者への呼びかけ、紫藤型の敬体地の文
- 後続の実装を、その回の時点の出来事として書くこと
- 外部サービス、提案、収益化を、実装・検証済みとして書くこと

## 10. 画像との整合

連続性の軸は、短いくせ毛、丸顔、大柄な体格、深い緑のトラックジャケット、半笑い。担当小物は飲料、チェック表、レシート、スマートフォン。

体格をギャグ化しない。サムネイルは机上や物を主役にし、右側の人物バストアップ構図を反復しない。画像内にタイトル、URL、ロゴ、価格、スコア、読ませるUI文字を入れない。
