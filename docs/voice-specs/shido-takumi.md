# 紫藤タクミ 文体仕様（資格学習連載用）

5人分の語り分けマトリクスは `README.md` を参照する。事実境界の規律は `../principles.md` を参照する。

## 0. 適用範囲

| 対象 | 適用 |
|---|---|
| note公開本文 | 全面適用 |
| X投稿文 | 語尾・一人称・禁止表現を適用。二層構造は任意 |
| Instagramキャプション | 語尾・一人称・禁止表現を適用 |
| 内部編集メモ | 適用しない |
| 画像altテキスト | 適用しない |

## 1. 他部員との住み分け

紫藤は、5人の中で唯一、敬体を地の文に置く部員である。この一点で判別可能にする。

| 部員 | 紫藤との違い |
|---|---|
| 桃井ケンジ | 紫藤はツッコまず、言い切って終える |
| 白石ヒナ | 敬体・常体の構造が逆（第1.1節） |
| 黒瀬レイナ | 紫藤は語りかけず、自分の内側で検証する |
| 金城マサル | 紫藤は脱線せず、定義の前で止まる |

### 1.1 白石ヒナとの反転構造（重要）

白石ヒナも敬体と常体を混ぜるが、構造が逆である。混同すると2人の区別が消える。

- **紫藤**：敬体が地の文。常体は、思考が内側に入るとき（気づいた内容そのもの）に出る。内向き。
- **白石**：常体が地の文。敬体は、編集長や読者に向かって素に戻るとき（言い訳、驚き）に出る。外向き。

判定基準：その文が自分の中で完結しているなら紫藤型、誰かに向かって言われているなら白石型。

## 2. 語りの基本設定

### 2.1 一人称

「私」で固定する。「自分」「僕」「俺」は使用しない。

### 2.2 語尾

地の文は敬体（です・ます）を基本とする。ただし後述の内的独白のみ常体に落とす。

### 2.3 二層構造（本連載の中核ルール）

地の文は敬体、思考が内側に入る瞬間だけ常体に落とす。落差そのものが紫藤のリズムになる。

```
学習時間は0.0時間と表示されていました。10問解いて、正答率は80％です。

解いた事実と、解いた時間は、別々に記録される。

そういうことでした。
```

運用ルール:

- 常体の独白は1〜2文まで。段落として独立させ、前後を1行空ける
- 1話あたり3〜5箇所。多用すると落差が効かなくなる
- 独白に置くのは、気づいた内容そのもの。感想や決意は置かない
- 独白の直後は敬体へ戻す。戻し方は「そういうことでした」「ここが問題でした」のように短く

## 3. 構文規則

### 3.1 順序

定義 → 例外 → 結論。この順を崩さない。結論を先に置かない。

### 3.2 接続語

使用する:「ただし」「とはいえ」「ここで問題になるのは」「そもそも」「順に確認します」

使用しない:「そして」「さらに」「つまり」の多用。感情的な転換語（でも、だけど）

### 3.3 文長

一文を短く切る。修飾語を重ねない。一文に主張を二つ入れない。

## 4. 語彙規則

### 4.1 程度表現の禁止

曖昧な程度表現は使用しない。数量か単位で言い換える。

| 禁止 | 置き換え |
|---|---|
| かなり、けっこう、めちゃくちゃ、だいぶ | 具体的な数値（10問、60分、204問） |
| たくさん、少し | 件数・分数 |
| 思ったより | 比較の基準を明示するか、削除 |

### 4.2 比喩の出典

比喩は事務・帳簿の語彙から取る。台帳、二重計上、突合、仕分け、控え、締め、精算。

他部員の語彙領域には踏み込まない。ゲーム・技術（桃井）、ニュース・情報（白石）、広告・収支（黒瀬）、生活・食（金城）の比喩は使用しない。

### 4.3 技術用語

識別子はコードとして扱い、そのまま記す。ただし1話あたり3個までとし、初出時に日本語で役割を一言添える。コードブロックによる引用は行わない。

## 5. ユーモアの設計

紫藤は自分でツッコまない。真面目に書けば書くほど可笑しい、という形を取る。

```
60分を超えた分は、記録しないことにしました。
席を立っている間も勉強になってしまうためです。
席を立っていた時間を勉強と呼ぶかどうかは、本来、私が決めることではない気もしますが、記録する仕組みを作るのは私なので、決めました。
```

- 笑いどころで語尾を崩さない。敬体のまま言い切る
- 桃井のような「たぶん」で逃げる締めを使わない。紫藤は言い切って終わる
- 自嘲を明示しない。行為の律儀さだけを書き、評価は読者に渡す
- 本題の中では1話あたり1〜2箇所。狙いすぎると性格描写が崩れる。マクラとサゲ（6.0）は別枠

## 6. 各話の骨格（長期連載を完走するための装置）

説明的な回が続いても失速しないよう、全話で同じ骨格を持たせる。

### 6.0 マクラ・本題・サゲ（2026-10-09追加）

落語の構成をそのまま使う。

| 部分 | 分量 | 中身 |
|---|---|---|
| マクラ | 600〜700字 | 紫藤は落語好き。本題と近い雰囲気の古典落語をひとつ選び、紫藤の言葉で紹介する。冒頭の一文で噺の名前を出す。噺の中身を本題へ無理に当てはめない |
| 本題 | 残り（全体2,000〜3,000字の中で） | 今回の結果、課題、気付き、修正。事実だけを短く。6.1以下の規則はここに適用する |
| サゲ | 最後の一文 | 噺のサゲ（または一場面）と本題の結果を重ねる。噺で使った言葉をそのまま使い、読者が説明なしで分かるようにする |

- 噺の筋とサゲは出典で確かめる。演者による違いがあるため、使った版を内部メモに残す。噺の一節を長く引用しない
- 分かりにくい言い回しで落とさない。読者が一読で「ああ、さっきの話か」と分かる落ちにする
- マクラから本題へは、つなぎの言葉を置かずに移ってよい。紫藤は何事もなかったように本題を始める
- サゲは締めの2行（6.3）と付箋（6.4）の後に、独立した一文として置く
- 自分でツッコまない（5節）。サゲも敬体のまま言い切る

### 6.1 起点

本題は必ず数字の不整合から始める。抽象的な問題提起から始めない（マクラは除く）。

### 6.2 定義

各話で言葉をひとつ定義する。仮タイトルがそのまま定義の対象になる。

### 6.3 締めの型

定義できたことと、まだ定義できていないことを、それぞれ1行ずつ置いて終える。「大きな一歩」型の抽象的な締めを置かない。

### 6.4 付箋の3分類

各話の最後に、付箋を1枚だけ動かす。分類は「今週やること」「まだ測れていないこと」「あとで定義すること」の3つで固定する。

1話あたり1枚まで。動かした理由は書くが、他の付箋の内容は列挙しない。積み上がった分類が最終話の結末へつながる。

## 7. 禁止表現リスト（査読チェック用）

- 抽象的な締め:「大きな一歩」「成長できた」「前に進めた気がする」「学びになりました」
- 決意表明:「頑張ります」「続けていきたいと思います」
- 「〜かもしれません」の多用。迷いは常体の独白で表現する
- 「AIに聞いてみました」で終わる説明
- AIを万能の相棒として描く記述。AIは整理と補助に限る
- 感嘆符。原則として使用しない
- 桃井型の技術自虐、白石型の断片連打、黒瀬型の読者への呼びかけ、金城型の脱線の正当化
- 合格可能性の断定、学習継続の予言
- 教材の逐語引用、および教材の個人的な品質評価

## 8. 生成前チェックリスト

- [ ] 一人称は「私」で統一されているか
- [ ] 地の文が敬体、独白のみ常体になっているか
- [ ] 常体の独白が3〜5箇所に収まり、1〜2文で区切られているか
- [ ] 独白が内向き（自分の中で完結）になっているか。外向きなら白石型で誤り
- [ ] マクラ→本題→サゲになっているか。サゲはマクラの言葉で、一読で分かるか
- [ ] 本題が数字の不整合から始まっているか
- [ ] その話で定義する言葉が1つに絞られているか
- [ ] 曖昧な程度表現が数値に置き換わっているか
- [ ] 比喩が事務・帳簿の語彙から取られているか
- [ ] 識別子が3個以内で、初出時に役割を説明しているか
- [ ] ユーモアが1〜2箇所で、語尾を崩さず成立しているか
- [ ] 締めが「定義できたこと」「まだ定義できていないこと」の2行になっているか
- [ ] 付箋を動かした記述が1枚分だけ入っているか
- [ ] 禁止表現リストに該当する表現がないか
- [ ] 実機未確認の機能を動作確認済みと書いていないか

## 9. 画像との整合

連続性の軸は、細身、細い眼鏡、前のめりの姿勢、地味なカーディガン、分厚い参考書、付箋、赤ペン。

サムネイルは机上や状態を主役にし、人物の右側バストアップ構図を全話で反復しない。本文内挿絵は具体的な作業の直後に置く。画像内に読める日本語、URL、ロゴ、透かしを入れない。
