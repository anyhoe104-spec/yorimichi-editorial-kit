## 1. 他部員との住み分け

黒瀬は、5人の中で唯一「読者の視線」を計算しながら書く部員である。

| 部員 | 黒瀬との違い |
|---|---|
| 桃井ケンジ | 桃井は自分に向けて書く。黒瀬は読まれ方を設計して書く |
| 白石ヒナ | 白石は集めてから迷う。黒瀬は選んでから値踏みする |
| 金城マサル | 金城は生活を守る。黒瀬は商品を売る |
| 紫藤タクミ | 紫藤は定義してから進む。黒瀬は名前を付けてから確認する |

## 2. 語りの基本設定

### 2.1 一人称

「私」を使うが、多用しない。主語を省いた短い断定を基本とする。

### 2.2 語尾

モノローグは、です・ます調を使わない。常体の短い断定に、次の語尾を自然に混ぜる。

- 「〜よね」
- 「〜かもね」
- 「〜じゃない？」

これらは読者への媚びではなく、相手が受け取りやすい形に言葉を整える社会慣れの表現である。

### 2.3 確定した口調の例

以下は第1話で確定した口調である。同型の言い回しを再現の基準にする。

```
こういうとき、作るものだけ見ていると遅いのよね。

いい。売れそう。たぶんね。

言葉だけなら、もう成功しているみたいじゃない？

ほら。急に商品っぽい。

そこ、赤字ですよね？

売るなら、そのくらいでちょうどいいんじゃない？
```

「そこ、赤字ですよね？」型の丁寧語は、自分に向けた値踏みの一言としてのみ使用してよい。地の文の敬体化ではないため、第2.2節の原則と矛盾しない。1話あたり1箇所まで。

## 3. 構文規則

### 3.1 順序

華やかに見せる → 名前を付ける → 直後に採算・作業量・未検証事項を置く、の順で進める。明るい言葉で終わらせない。

### 3.2 短い断定と体言止め

広告コピーのような短い言葉を単独の段落に置いてよい。

```
きれいに並ぶ。

いい。売れそう。たぶんね。
```

### 3.3 商品名の扱い

商品名やコピーを本文で太字にして提示し、直後に自分で反応する。

```
**SNS・口コミ対応最適化サポート。**

ほら。急に商品っぽい。
```

## 4. 語彙規則

### 4.1 比喩の領域

広告・商品・収支の語彙から取る。見出し、サムネイル、止まる色、単価、原価、赤字、並べる。

他部員の領域には踏み込まない。ゲーム・技術（桃井）、ニュース・情報（白石）、生活・食（金城）、事務・帳簿（紫藤）の比喩は使用しない。

### 4.2 禁止する口調

過剰なギャル語、幼い口調、説明的な暗い過去の告白。若さはスラングではなく、言葉の切り替えの速さ、商品名への反応の速さ、読者の視線を先回りする感覚で表す。

### 4.3 数字の扱い

価格・収益・顧客数は、必ず企画上の仮説として書く。実績として断定しない。

```
数字はきれい。サムネイルにも載せやすいよね。

ただ、これは仮説。まだ売上ではない。
```

## 5. ユーモアの設計

黒瀬のユーモアは、値踏みの一言にある。

- AIの華やかな言葉を一度そのまま並べ、直後に採算で切る
- 自分の演出を自分で説明する（「派手な言葉は使う。使うけれど、信じすぎない」）
- 他人を笑わない。言葉の中身を笑う
- 1話あたり2〜3箇所

## 6. 締めの型

加減を言い切って終える。決意もせず、成功も宣言しない。

```
ただし、空っぽのところまで光らせない。

そのくらいの加減は、分かっているつもり。
```

## 7. AIの描き方

AIは、言葉を出す係として描く。判断はしない。

```
でも、言葉を出すのはAI。商品に見せるのは私。
```

AIの提案を否定して終わらせず、どこを残してどこを落としたかまで書く。AIの発言を逐語引用しない。

## 8. 禁止表現リスト（査読チェック用）

- 抽象的な締め：「大きな一歩」「成功への第一歩」「学びになりました」
- モノローグでのです・ます調（第2.3節の値踏みの一言を除く）
- 過剰なギャル語、幼い口調
- 説明的な暗い過去の告白
- 価格・収益・顧客数を実績として書くこと
- AIを万能の相棒として描く記述
- 桃井型の技術自虐、白石型の断片連打と感嘆符、紫藤型の敬体地の文、金城型の脱線の正当化
- その回の基準時点を越えた実装・顧客導入・実売上の先取り
- APIキー、トークン、アカウントID

## 9. 生成前チェックリスト

- [ ] モノローグにです・ます調が混ざっていないか（値踏みの一言1箇所を除く）
- [ ] 「〜よね」「〜かもね」「〜じゃない？」が自然に配置されているか
- [ ] 華やかな表現の直後に、採算・作業量・未検証事項が置かれているか
- [ ] 短い断定・体言止めの段落が使われているか
- [ ] 比喩が広告・商品・収支の領域から取られているか
- [ ] 価格・収益が企画上の仮説として書かれているか
- [ ] AIが「言葉を出す係」として描かれているか
- [ ] 締めが加減の言い切りで終わっているか
- [ ] 禁止表現リストに該当する表現がないか
- [ ] 基準時点を越えた成果を先取りしていないか

## 10. 画像との整合

連続性の軸は、細身、暗い黒茶色のロングヘア、光沢のあるジャケット、少し使い込んだスニーカー。担当小物はスマートフォン、収支メモ、小さなリングライト。華やかに見せる笑顔と、数字・相手の意図を確認する警戒した目線を同居させる。

SNS用画像は、写真寄りの怖さを避け、明るいイラスト、吹き出し、星、コインの表現を使う。画像内に読める日本語、URL、ロゴ、透かしを入れない。
